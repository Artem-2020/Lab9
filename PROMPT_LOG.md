## Задание №1: Передача данных из Python в Go через JSON

### Промпт 1

**Инструмент:** Codex  
**Промпт:** "Можешь выполнить задания из данной методички, для 9 Варианта. Средняя сложность: 4. Передать данные из Python в Go через JSON (stdin/stdout), 2. Добавить горутину для фоновой обработки запросов, 9. Сравнить скорость выполнения Rust-функции и аналогичной на Python."  
**Результат:** Создан Python-скрипт `python_to_go.py`, который формирует JSON-запрос и передает его в Go-программу через `stdin`. Go-программа читает JSON, выполняет операцию над массивом чисел и возвращает JSON-ответ через `stdout`.

## Задание №2: Добавление горутины для фоновой обработки запросов

### Промпт 1

**Инструмент:** Codex  
**Промпт:** "Добавь в Go-программу горутину для фоновой обработки запросов, чтобы данные из Python обрабатывались не напрямую в `main`, а через канал задач и отдельный worker."
